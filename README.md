# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Theerthananda/theerthananda.github.io.git
```

Go inside

```bash
cd theerthananda.github.io
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build production

```bash
npm run build
```
